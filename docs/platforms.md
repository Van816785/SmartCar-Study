# 智能车平台对比

| 平台 | 典型优势 | 主要限制 | 适用方向 |
| --- | --- | --- | --- |
| STM32F1/F4 | 资料多、工具链成熟、成本低 | 图像算力和内存有限 | 光电、基础循迹、控制板 |
| K60/K66 | 往届摄像头组资料丰富 | 旧工具链和 SDK 维护成本 | 学习经典摄像头方案 |
| TC264 | 多核、PWM 和定时器资源较强 | 工具链和调试门槛较高 | 摄像头组、复杂实时控制 |
| CH32V307 | 国产 RISC-V、外设丰富、成本较低 | 生态和往届资料较少 | 新平台验证 |
| Linux 开发板 | OpenCV 和调试工具完整 | 供电、启动时间、实时性与成本 | 视觉实验和复杂感知 |

选型必须先确定车辆、传感器、采样率、图像分辨率和供电，而不是先买性能最高的板。
