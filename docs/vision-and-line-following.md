# 视觉与循迹笔记

## 基础摄像头方案

1. 固定曝光和增益，先消除场地灯光的周期性波动。
2. 使用连续多帧确认赛道边界，单帧跳变只能作为候选。
3. 将图像坐标先转换为车辆前视距离和横向偏差，再做控制。
4. 在直道、弯道、十字和环岛分别验证状态机。

## 线性 CCD 方案

1. 记录黑白标定值，避免只用硬编码阈值。
2. 对环境光做开灯/关灯差分采样。
3. 根据赛道宽度和传感器视场换算横向偏差。
4. 舵机和速度控制应分别限幅、限加速度和设置故障停车。

## 通用安全策略

- 丢线后先减速，再按受限搜索动作恢复。
- 十字和环岛必须是状态机，不应只看单帧特征直接切换。
- 所有模式都要有超时、置信度和恢复路径。
- 控制参数集中在单独配置文件中，并记录每个参数的来源和适用范围。
