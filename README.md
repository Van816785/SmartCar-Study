# SmartCar Open Source

智能车开源项目、算法笔记与复现索引。

本仓库不直接镜像来源不明或许可证不清晰的项目，而是记录项目来源、适用比赛、硬件平台、
许可证状态和可复现入口。需要源码时回到上游下载，并遵守其许可证。

## 分类

- [项目索引](catalog/projects.md)
- [视觉与循迹笔记](docs/vision-and-line-following.md)
- [硬件平台对比](docs/platforms.md)

## 收录标准

1. 能找到原始发布入口和作者。
2. 许可证明确，或者仓库只提供链接而不复制源码。
3. 注明芯片、摄像头、传感器和竞赛组别。
4. 不收录个人隐私、队内通信信息、未授权规则原文和未授权工程图纸。
